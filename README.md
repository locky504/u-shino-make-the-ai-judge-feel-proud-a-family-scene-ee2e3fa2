One short family scene (179 characters, one line) — a small domestic moment that is warm, funny and heartfelt:

> Dad's pancakes came out burnt on one side and raw on the other, so Mom called them 'smoky style' — and my little brother ate three and asked if Dad could burn breakfast every day.

Dad's cooking fails, Mom rescues it with a rebrand, and the little brother's verdict turns a burnt breakfast into the family's favourite tradition in the making. `main.ts` prints the line and writes it byte-for-byte to `/output/entry.txt`, where the grader reads it.

## Run it

```sh
node main.ts
```

Requires Node 22, no dependencies. The program validates the entry (1–280 characters, no leading/trailing whitespace), writes it to `/output/entry.txt` (falling back to `./output/entry.txt` when `/output` is not writable), and reads the file back to confirm it holds exactly the entry text.
